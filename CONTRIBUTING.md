# Contributing to Project Hello UI (Portov)

Contributions from developers, testers, and designers are welcome!

### How You Can Help
1. **Testing & Bug Reports:**
   * Test hardware features (Wi-Fi, Bluetooth, Camera, Audio, Refresh Rate, Fingerprint).
   * Submit detailed bug reports with `adb logcat` output.
2. **Overlay & Configuration Fixes:**
   * Refine RRO overlays for screen cutouts and refresh rate profiles.
   * Improve Moto Camera feature flags and tuning configs.
3. **Script Optimization:**
   * Enhance `sparse_extractor.py`, `patch_portov.py`, or cross-platform flashing scripts.

### Submission Guidelines
* Do NOT commit raw `.img` files, `.zip` dumps, or proprietary blobs over 100MB to git.
* Keep commit messages descriptive (e.g., `portov: overlay: Adjust status bar padding for 120Hz`).
* Ensure scripts follow clean Python 3 / Bash / Batch coding standards.
